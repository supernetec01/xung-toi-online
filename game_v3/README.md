# Mã nguồn game hiện tại

Chạy từ root repo: `npm ci && npm start`. Cổng local **5001**. Hướng dẫn và kiểm thử mới ở `../README.md`, `../docs/QA.md`.

`npm run verify` tại thư mục này vẫn kiểm tra cú pháp/catalog. Các HTML tự chứa là snapshot lịch sử, không được cập nhật theo src và không được server phục vụ.
