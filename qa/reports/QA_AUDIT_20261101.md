## Cập nhật và rollback

Không có migration mới trong đợt QC. Hai field movement thêm vào JSON là tương thích bổ sung. Dữ liệu demo/local và vật phẩm sở hữu không bị xóa. MFA-enabled PLAYER có phiên cũ thiếu OTP sẽ cần đăng nhập lại.

Windows PowerShell, trong thư mục repo, dừng tiến trình app cũ bằng Ctrl+C rồi:

```powershell
git pull --ff-only origin main
npm.cmd ci
npm.cmd run db:start
npm.cmd run db:migrate
npm.cmd start
```

Mở `http://localhost:5001`. `npm.cmd ci` cần chạy để nhận bản dependency đã vá. `db:start` cần Docker Desktop/engine đang chạy; giữ nguyên `.local/`, database, encryption key và uploads. Máy cài mới có thể chạy `npm.cmd run admin:bootstrap` rồi đọc thông tin riêng tại `.local/operator.json`; xem [README](../../README.md). Không gửi file này lên chat/Git.

Rollback: sao lưu bằng `npm.cmd run db:backup` trước cập nhật; giữ DB/khóa mã hóa hiện có. Có thể hoàn nguyên riêng UI/asset bằng commit đảo trên branch mới rồi chạy các test liên quan. Không rollback toàn bộ auth/import về baseline đang có lỗ hổng. Nếu có sự cố import, đặt `DEMO_IMPORT_ENABLED=false` trong môi trường process rồi restart; không khôi phục dump cũ để đảo UI vì sẽ mất tiến độ mới. Nếu movement phát sinh vấn đề, rollback client và validator cùng nhau trên staging, giữ MFA/import patch, kiểm tra rồi mới cập nhật bản đang dùng.
